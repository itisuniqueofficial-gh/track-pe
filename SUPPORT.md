# Support

Track Pe is an open-source project by **It Is Unique Official**, maintained on a
best-effort basis.

For questions, feature requests, and community discussions:

- **GitHub Discussions:** https://github.com/itisuniqueofficial-gh/track-pe/discussions

For technical bugs:

- **GitHub Issues:** https://github.com/itisuniqueofficial-gh/track-pe/issues

For private / security-related concerns:

- **Email:** track-pe@itisuniqueofficial.com
- or use [GitHub Security Advisories](https://github.com/itisuniqueofficial-gh/track-pe/security/advisories/new)

## Before opening an issue

- Check existing issues and discussions to avoid duplicates.
- Never include UPI IDs, payment details, or secrets.
- Include your Flutter/Dart version (`flutter --version`) and platform.

## Reminder

Track Pe does not process or settle UPI payments and is not financial advice.
